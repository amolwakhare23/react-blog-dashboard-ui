
# Blog Management Dashboard Project
This project is a responsive Blog Management Dashboard built with React and Material UI v5. It allows you to perform CRUD (Create, Read, Update, Delete) operations on blog posts, with data stored locally in your browser's localStorage. It also features a light/dark theme toggle.
